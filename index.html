RCC Command Center

RCC Command Center is a private, personal productivity dashboard operated by RealChangeCollective for a single user. It reads the user's own email and calendar to produce a daily summary.

Privacy Policy

Last updated: October 2026

This application is for personal use by its operator only. It is not offered to the public and has no other users.

What it accesses: With the user's explicit consent, the application reads the user's own Gmail messages and Google Calendar events on a read-only basis, to generate a private daily briefing.

How data is used: Data is processed locally on the operator's own hardware to produce summaries. The application does not sell, share, or transmit the user's email or calendar data to any third party.

Data retention: Derived summaries are stored locally on the operator's own machine. The user may revoke the application's access at any time via their Google Account security settings.

Contact: For any questions about this application, contact the operator at the email associated with this Google Cloud project.
